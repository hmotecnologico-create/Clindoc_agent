# ClinDoc Agent
> Plataforma Multi-Agente para Auditoría Clínica con LLM Local

## Descripción
ClinDoc Agent es un sistema de inteligencia documental para la revisión automatizada de expedientes clínicos.

## Requisitos
- Python 3.10+
- Ollama (servidor local de LLM)
